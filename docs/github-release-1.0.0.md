Explore Harvard Veritas — The Living Archive, an independent interactive web experience by Guilherme Galvão.

[Open the experience](https://gpereiradeveloper-rgb.github.io/Harvard-Project-site-with-3d-Animation/)

- Animated opening, a geographic 3D approach to Memorial Church, a living archive and six interactive editorial volumes with 36 pages.
- Refined campus framing, clearer grounds and landmark highlights; page scrolling now advances the camera without the blue gesture overlay.
- Corrected forklift insertion, withdrawal and return clearances, checked against imported mesh envelopes throughout the operation.
- Lighter mobile delivery: opening film about 0.36 MB on mobile / 0.80 MB on desktop; seven active photographs reduced from 40.23 MB to 2.27 MB combined. Character and device delivery also optimized.
- English interface, source references, visible geographic attribution and adaptive rendering quality.

Built with React, Three.js, React Three Fiber, GSAP, MapLibre and OpenFreeMap. The public map requires no API key or enabled billing; it uses cartographic building extrusions rather than photographic 3D imagery.

Visual studies by Alex Bender / Fancy and Vedant Hegde informed the material, lighting and motion direction. This is an independent creative study with no institutional affiliation with Harvard University. Asset authorship and licensing are documented in the repository.

Validation: production build passed; 16 choreography and clearance tests passed for the preceding scene release. The final map style passed MapLibre validation and both camera paths were checked over 1,001 samples. A native Safari preview confirmed the campus presentation; performance varies by device.
